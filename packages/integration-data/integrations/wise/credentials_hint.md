1. Choose the credential variant that matches the environment you want to connect: Production Personal API Token for https://api.wise.com, or Sandbox Personal API Token for https://api.wise-sandbox.com.
2. For production, log in to your Wise business account at https://wise.com/. For sandbox, log in to the Wise sandbox at https://wise-sandbox.com/.
3. Go to Your Account > Connect and manage apps > API tokens.
4. Click Add new token and complete Wise's two-step verification prompt.
5. Copy the token when Wise shows it. It is only displayed once.
6. Paste the token into Commandable. Production tokens only work with the production variant; sandbox tokens only work with the sandbox variant.
7. Personal API tokens can prepare transfers, manage recipients, and read transfer status, but this integration does not fund transfers via API.
